# Build it three ways:
#
#   #+MOSAIC_OUTPUT: split     double-width pages: slide | notes
#   #+MOSAIC_OUTPUT: speaker   A4, slide thumbnail above its notes
#   #+MOSAIC_OUTPUT: notes     A4, notes alone
#
# Then present with either console:
#
#   pympress presenter.pdf              splits automatically
#   pdfpc --notes=right presenter.pdf   tell pdfpc which half is notes

* Notes that apply to a whole slide

** What a console shows you

A presenter console drives two displays: the projector shows the slide,
your laptop shows the same slide with its notes, the next slide, and a
clock.

- pympress reads a double-width page automatically
- pdfpc needs =--notes=right=

* Restyling the notes half

** The notes use their own labels

The notes half stays black on white whatever the deck does, because it
is read off a laptop under house lights rather than projected.

#+MOSAIC: #show label("mosaic-note-body"): set text(size: 11pt)

#+begin_note
Both printed outputs and the split output use =<mosaic-note-heading>=
and =<mosaic-note-body>=, so one rule restyles all three.

If a note overflows its half the compile fails and names the frame;
raise =#+MOSAIC_NOTES: (split-inset: 6mm)= to give it more room.
#+end_note
